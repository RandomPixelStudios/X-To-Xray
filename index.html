Installation

Ready in a minute.

  1. Install a compatible version of Minecraft.
  2. Install the Fabric Loader (or another supported loader).
  3. Download X To Xray for your Minecraft version.
  4. Download the Fabric API for your Minecraft version.
  5. Put both files into the mods folder of your Minecraft installation.
  6. Launch Minecraft.
How to use

Press X.

  1. Launch Minecraft with the mod installed.
  2. Create a new world, or join a server that has X To Xray installed on the server side.
  3. Press X to turn Xray on or off.
  4. Type /config or open the escape menu and click the config button to change settings.
